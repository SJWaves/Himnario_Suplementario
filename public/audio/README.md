# Audio de himnos

Los archivos se nombran por número de himno: `1.mp3`, `2.mp3`, … `10.mp3`.

- **Origen:** `Himnario_Suplementario_instrumental/`
- **Himno 3** (Tranquila Mi Alma): no hay pista en la carpeta; ese himno se muestra sin reproductor.
- **Himno 9:** solo existe en `.mp4`; se usa `9.mp4`.

Vite sirve todo lo que está en `public/` en la raíz, así que las rutas son `/audio/1.mp3`, etc.
